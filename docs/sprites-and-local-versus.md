# 날아라 꽃돼지 — 캐릭터와 로컬 2P (2026-10-29)

## 적용 범위
- 연이: 공식 둥근 꽃돼지·연꽃·보라 스카프와 반투명 날개. 영냥이: 흰 고양이·마법사 모자·고글·하늘 오토바이.
- 각 시트 1024×1536, 4열×6행. 0–15 비행, 16–19 획득, 20–23 충돌. 행 우선 순서.
- 표시 상자 70×70 논리 픽셀(초안의 87.12보다 약 20% 축소). 기존 1P 물리 크기 70×(70/1.15), 난이도 hitPad와 천장/바닥 pad 0.18 유지. 2P도 동일 공식.
- 장애물 통과는 점수·파티클만. 획득 애니메이션은 실제 collectItem에서 시작하며 첫 프레임부터 한 번 재생. 2P 보석도 각 플레이어가 실제 획득할 때만 반응.
- 로컬 2P는 같은 기기에서 같은 시드의 장애물/보석 코스로 경쟁. 1P W, 2P ↑ 또는 각 화면/버튼 터치. 같은 아이템을 각각 수집 가능. 더 오래 생존한 팀 승리, 같은 틱 사망은 점수 비교 후 동점이면 무승부.
- 2P는 별도 대결 기록이며 기존 1P 점수·해금·저장 키를 변경하지 않는다. 온라인 멀티플레이가 아니다.
- 팀 이름·꽃/별 문양·분홍/보라 색상으로 플레이어 구분. 기존 Nanum Pen Script 서체 재사용.

## 2026-10-29 추가 보완
- 2P에 기존 STAGES/DIFFICULTIES 정본을 전달한다. 속도(3px × 스테이지 × 난이도), 틈(최소116px), 생성 간격, 이동 확률/강도, 오오라 시작 단계를 반영한다. 두 플레이어가 공유하는 통과 거리로 스테이지가 진행하며 배경·기둥 테마도 바뀐다.
- 연꽃 보호막/중독 해제, 클로버 통과 점수2배, 추진 아이템 보호 효과, 행운 아이템 점수는 플레이어별 적용. 2P 추진 아이템은 공정한 공통 장애물 속도를 바꾸지 않는다. 바닥/천장은 보호막으로 막지 못한다.
- 점프·통과·아이템 종류별 획득·충돌·오오라 중독·스테이지 효과음을 기존 오디오 함수로 연결. 2P 효과음 토글을 제공하며 음악과 별도 보존한다. 같은 틱 같은 효과음은 중복 재생하지 않는다.
- v3 시트: 내장 image_gen으로 날개의 상승/하강과 하늘 오토바이의 대각선 추진 분출을 새로 제작. `tools/pack-sprites.cjs`가 알파32 이상 실제 연결 성분을 찾아 인접 셀 침범 없이 분리하고, 캐릭터 몸 중심 기준으로 같은 배율·256px 셀에 재배치한다. 비행에 섞인 웃음 포즈는 제외하고 날갯짓의 역방향 구간으로 연결한다. 원본을 무조건 4×6 격자로 자르지 않는다. 미세 가장자리2px만 보존하고 주변 노이즈를 배제한다.
- 최종 시트/프로필: assets/sprites/{yeoni,yeongnyangi}-v3.webp, *-portrait-v3.webp. JSON은 원본 프레임 순서와 절단 후 영역·중심점 기록. 양쪽48프레임 외곽12px의 불투명 픽셀0을 실제 브라우저 캔버스에서 확인했다.
